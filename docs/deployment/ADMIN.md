# 后台管理功能与角色权限

超级管理员拥有全部后台业务管理权限，不需要再找另一种“更高权限账号”。运营和售后继续按职责分工，权限由服务端验证，不只是隐藏按钮。

## 紧凑工作台入口（v2.6.0）

- CDK 管理默认显示授权码列表，点击“套餐管理”“批次管理”标签切换；“新建套餐”和“批量生成”按钮打开居中表单，提交后切换到对应列表。
- 管理员的密码/2FA/会话/删除，任务的审核/返还/取消/删除，目录的上下架/恢复默认，以及备份的恢复/备注/删除均保留在对应行的“更多”菜单中。CDK 的复制/删除也可从“更多”进入。
- 备份页顶部“定时备份”打开每日备份设置；上传、创建、下载、预览仍可直接操作。
- 更新事件、安全基线与概览说明可展开查看，更新状态、操作按钮和故障提示仍直接显示。
- 菜单支持方向键、Home/End、Esc 关闭并返回焦点；标签页支持左右方向键切换。布局不改变原有字号和暖黑金色/亮色主题。

## 任务售后

可按任务 ID、目标服务器、任务类型、执行状态和售后状态筛选，支持分页。导出按钮导出全部任务，不限当前页。

“详情与处理记录”展示服务器、项目、执行步骤、事件、失败原因、残留及 CDK 核销摘要。部署登录密码和一次性交付凭据不写入持久化任务历史，因此刷新后不能从这里还原客户的安装密码。

售后审核状态可设为“待处理 / 处理中 / 已解决”，审核备注可修改或删除；可以另外创建多条处理记录，分别修改、删除。操作均记入审计，不会因为覆盖备注而完全失去操作轨迹。任务真实执行状态由执行器产生，不提供把失败任务伪造为安装成功的按钮。

返还次数按任务幂等处理：已消费的权益退回一次，锁定权益释放，已经释放或返还的任务不会重复增加次数。删除审核记录不撤销次数返还，也不能借此重复返还。

运行中的任务需要先安全取消，等待状态变为已结束再删除。仅超级管理员可删除整个任务，删除同时清除它的步骤、事件、审核和处理记录，但保留 CDK 权益账本和删除审计。**删除记录不会卸载客户服务器上的项目，也不会自动返还次数；需要返还时先处理返还，再删除。**

## 套餐与批次

修改套餐次数会影响没有单独覆盖次数的已有 CDK；不能低于其已用和锁定次数。有效天数只影响以后生成的 CDK，不重写现有 CDK 的到期时间。已有 CDK 可单独编辑有效期。

套餐支持限定项目 ID 和分类；留空表示不限。存在锁定任务时不能修改授权范围。停用套餐后不能再生成新 CDK。

删除套餐或整个批次需居中弹窗明确确认，关联 CDK 与授权记录会同时删除，无法撤销；请先导出并处理售后。存在运行任务或锁定权益时需先完成/取消任务。

## 管理员与备份

重置密码最低 6 位；重置密码、重置 2FA、停用或撤销会话会使相应其他会话失效。不能在当前会话中删除、停用或降权自己，避免后台无人可用；可用另一超级管理员账号操作。删除管理员保留其业务数据和原有审计身份。

备份备注不改动加密文件。删除备份会移入服务器数据目录 `backups/.trash`，服务器管理员可恢复文件；前台列表中移除该记录。正在保护更新的备份不能删除。部署或更新执行期间不可恢复数据库，以免切断运行任务。恢复其他旧备份前自动创建恢复前快照。

每日自动备份需要在服务器环境变量配置 `PANELARK_BACKUP_PASSPHRASE`，重启服务后可在页面开启；手动备份不依赖此配置。

恢复后会注销全部历史管理会话并回到恢复后后台路径的登录页；恢复前快照、源备份及仍在本机磁盘上的其他备份继续保留在列表。备份里历史排队/运行中的任务会标记为中断，不会伪装成仍在安装；可检查目标服务器后继续售后处理。

## 目录与审计的业务边界

目录管理面向已经实现的真实安装适配器。上架/下架决定用户能否安装，恢复默认会清除自定义覆盖。不能只新增一个名字就声称有新项目的自动安装能力；新安装器必须随程序发布。

审计记录是历史事实，不支持改写内容。超级管理员可导出全部记录，并按过去的截止日期永久清理旧记录。清理操作本身会产生新的审计；清理前建议导出。
