# 目标服务器全自动部署与结果交付

本页说明通过 PanelArk 给客户 VPS 安装项目，不是 PanelArk 自身的宝塔／1Panel 网页安装向导。

## 用户操作

1. 验证 CDK，查看套餐、总次数、已用次数和剩余次数；其他任务占用的额度另列。
2. 填写服务器 IP／域名、SSH 端口、用户名及密码或私钥。
3. 连接后选择需要安装的面板或工具，等待系统返回结果。

安装阶段不再要求用户确认指纹、依赖、Docker、端口或防火墙。提交 SSH 信息表示授权本次连接，系统记录该连接实际主机指纹，再用同一 SSH 会话执行。适用系统和资源要求仍在项目卡片公开展示。

## 自动处理范围

- 检查系统、架构、systemd、内存、磁盘、root／免密 sudo 权限和项目专属限制。
- 自动安装缺失的基础依赖；容器项目缺 Docker Engine／Compose 时自动补齐、启动并验证，不重复安装已满足的组件。
- 3x-ui、New API、One API 和 CPA 主端口冲突时分配空闲端口。固定端口冲突会安全失败，不停止已有业务、不覆盖现有项目。
- UFW／firewalld 自动放行并验证本机规则。无法安全处理的其他防火墙返回原因和处理建议。
- 保留原项目安装后的服务验证，继续执行账号初始化或真实入口读取。New API、One API、Portainer、Nginx Proxy Manager、CasaOS、Marzban、哪吒和 Uptime Kuma 核验登录；其他面板沿用安装器实际生成的账号／入口。Hiddify 返回实际管理员专属链接，不伪造通用首页为管理入口。
- 安装成功由后端自动核销一次 CDK，失败释放额度，不依赖浏览器继续发送核销请求。最终结果再次显示次数。

云厂商安全组、DNS 控制台和第三方账号 OAuth 不能靠服务器 root 权限代为修改或授权。CPA 已安装不代表已拥有第三方账号和模型渠道；用户仍需使用自己的 OAuth／API 凭据。系统不采集第三方账号密码。

## 交付规则

成功返回实际地址、安全路径、账号、密码、Token／管理密钥等适用信息。支持单项复制、复制全部与 TXT 下载；普通 HTTP 环境提供复制兼容处理。

结果弹窗与站点亮／暗主题一致，不自动关闭，没有右上角关闭按钮，点击遮罩和 Esc 均不会关闭。必须由用户主动点击“我已保存，关闭结果”。

**刷新、关闭或离开页面后，不可重新查看本次结果。请先保存。** 交付凭证仅存在当前页面 React 内存，不写 Cookie、localStorage、sessionStorage、URL 或任务历史。服务端结果也只在内存，显式关闭即清除；已放弃的页面在后续请求清理闲置记录。服务重启不恢复敏感结果。

刷新不会终止已经提交到后端的安装任务，但会失去本页面交付凭证；不要因刷新后看不到结果而盲目重复安装。可联系管理员核对任务状态，并通过目标项目的官方管理命令处理账号恢复。

## 失败处理

展示实际失败原因、任务编号与针对性建议：SSH 认证／网络、系统／资源不兼容、权限不足、固定端口冲突、已有项目、依赖安装或服务／登录验证失败。若安装已创建账号而后续核验失败，会保留已获取的信息，明确标识尚未完成验证，不把失败当成功。

中途失败可能留下目标服务器文件或容器，不会自动删除未知数据。请先检查并备份，修复原因后重试。服务重启时不会在缺 SSH 凭据的情况下自动重装。

## 验证范围

自动化测试覆盖前端无中间确认、Strict Mode 不重复创建安装、手动关闭和刷新不可恢复、次数显示、自动依赖与端口、防火墙命令、各账号初始化协议、结果隐私、成功核销与失败释放。使用本地 SSH 测试服务和受控上游响应，不等同于所有面板在所有 Linux 发行版的实机验收。
