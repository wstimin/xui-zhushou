# v2.3.3：完整 CDK 管理

- 新生成 CDK 加密保管，管理员可重新查看、复制，导出 TXT 或 CSV，不再只显示一次。
- 支持按状态、套餐、批次与授权码搜索；全量筛选导出不受分页限制，也可导出选中记录。
- 增加单条次数、有效期与状态编辑，单条与批量删除、批量启停，删除使用居中主题确认弹窗。
- 超级管理员与运营管理员拥有完整 CDK 管理权限，普通前台保持隔离；提供普通 HTTP 环境的复制兼容处理。
- 旧版哈希记录不作废，不伪造明文恢复；管理员可绑定保存的匹配原码，以后正常查看和导出。
- 增加旧库迁移、加密恢复、跨分页导出、备份恢复、权限和 CSRF、任务占用与批量原子性、页面操作回归测试。
- 本次不更新远程服务器，使用者自行更新。
