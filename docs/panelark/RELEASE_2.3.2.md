# v2.3.2：正式产品展示与公开信息边界

- 前台目录、部署确认页和本地备用目录不再携带或展示内部验收标签、测试环境记录。
- 保留 Linux 发行版与版本、CPU 架构、内存、磁盘、systemd、网络要求和自动安装依赖说明；安装前的兼容性预检不变。
- 公开适配器列表与详情接口使用明确字段白名单，不再直接返回完整内部元数据；管理接口继续要求管理员登录和相应权限。
- 部署交付结果不再包含内部验收状态字段。
- 删除本地目录预设的已安装状态；未连接目标服务器或未获取项目状态时，不显示虚构的已安装 / 未安装标签。
- 增加公开目录字段、部署确认内容、管理员接口访问控制、任务归属与敏感结果脱敏的回归检查。
- 此版本不增加任何 Linux 系统兼容性承诺，也不修改现有服务器部署。
