# v2.4.0：精简用户端与全自动安装

- 删除用户首页和关于，默认进入面板部署；文档更名为部署文档，资源推荐独立分区。
- 删除顶部购买 CDK，只在验证 CDK 同行保留入口，点击仍读取后台最新链接。
- 用户填写 SSH 信息并选择项目后，自动检测环境、补齐依赖／Docker、处理端口和本机防火墙、安装并核验，无中间确认。
- 补齐多项目管理员自动初始化和登录验证，返回真实账号或实际管理员专属入口，不伪造结果。
- 结果不会自动关闭、遮罩和 Esc 不关闭，可复制或下载后主动关闭；刷新或离开页面后不可重新查看，不保存浏览器交付凭证。
- CDK 验证后显示总次数、已用、剩余与任务占用情况；成功自动核销，失败释放，结果页更新次数。
- 自动化回归覆盖成功、失败、权限、任务去重、敏感结果隔离与交付规则；未对客户服务器执行更新，也不宣称全系统实机验证。
