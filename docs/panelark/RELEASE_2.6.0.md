# v2.6.0：紧凑后台工作台

## 布局变化

| Before | After | Why |
| --- | --- | --- |
| CDK 页常驻两块新增表单及三个列表 | CDK／套餐／批次标签页，新增和批量生成使用居中弹窗 | 常用列表优先，不让低频表单占首屏 |
| 六个大统计卡片按四列形成空缺 | 统计卡片约 104px 起，按宽度使用六列／三列／两列 | 减少留白，统计数字与字号不缩小 |
| 表格每行堆叠多个操作按钮 | 保留主要操作，次要操作收纳到“更多” | 避免按钮换行撑高记录 |
| 版本、日志、安全详情占用大量竖向空间 | 紧凑状态条，事件和安全详情按需展开 | 操作与结果直接可见，明细仍可访问 |
| 账号左右卡片强制等高，设置表单长列排布 | 卡片按内容高度排列，站点设置按分区栅格排列 | 移除无内容留白，保留输入框与字体可读性 |
| 定时备份设置常驻大卡片 | 页头按钮打开设置弹窗 | 文件列表直接呈现 |

## 保留项

- 暖黑深棕＋金色和亮色主题共用原色板；不缩小原有正文、表格、输入框、标题或统计数字字号。
- 所有管理接口、角色权限、创建/编辑/保存/删除、导出、售后返还、备份恢复和账号安全功能保持可用。
- 新增菜单渲染在页面顶层，避免被横向滚动表格裁切；支持方向键导航、跳过禁用操作、Esc 返回焦点、Tab 离开及外部点击关闭。
- 标签切换无装饰性转场，保持频繁操作直接响应；弹窗继续使用原有主题。

## 验证方式

`server/admin-layout.test.tsx` 检查标签键盘切换、菜单裁切层级/焦点/关闭与禁用项、响应式 CSS、字号和色板约束。

更新 `server/admin-acceptance.test.tsx` 等既有测试，实际从新标签、弹窗和“更多”菜单点击操作，调用隔离的真实 HTTP 服务和 SQLite，继续核对文件、导出、删除、恢复、登录及重新加载。不是只验证按钮存在。

未使用 tabbit 或更新客户服务器。本轮自动化覆盖 DOM 交互与 CSS 约束，不冒充真实浏览器视觉验收。
