# v2.3.1 新增项目实机验收

日期：2026-10-17（Asia/Shanghai）。执行环境为用户授权的测试 VPS，未将服务器 IP、SSH 凭据、面板密码或备份内容写入此文档。

## 测试环境与方法

- Debian GNU/Linux 12（bookworm），amd64，Linux 6.1.0-13-cloud-amd64。
- 1 核，实际内存 977 MB，约 5 GB 系统盘，1 GB Swap。
- Docker 20.10.24，Compose 1.29.2。
- 使用项目真实服务端适配器，通过 SSH 实际执行安装及验证命令；管理员登录和鉴权另以真实 HTTP 请求验证。
- 经用户授权卸载原 PanelArk 程序与默认 Nginx，原业务数据与恢复备份保留在服务器。为控制资源，各 AI 面板逐个安装、验证并清理测试容器和镜像；最终保留宝塔运行。

## 实测修正

- 宝塔原先要求 5 GB 可用磁盘过于保守，导致满足纯面板安装条件的机器被拦截。调整为 1 GB 预检门槛，并将 5 GB 明确为建站预留建议。本机宝塔面板目录实际约 655 MB。
- 宝塔安装信息去除终端 ANSI 颜色控制符，保持网页交付信息可读；敏感字段继续脱敏保存。
- 补齐真实 SSH 环境检测命令中的内核、glibc、systemd 版本与 CPU 核数；本机重新检测得到 Linux 6.1、glibc 2.36、systemd 252、1 核。
- 项目卡片和部署确认页分别标示“实机已测”与“适用系统”，不将单系统验收误表述为全部系统通过。
- AI 项目增加发行版与版本白名单；新安装至少保留 1 GB 磁盘，避免在明显不足的环境中下载镜像。宝塔 ARM 软件兼容性不完整，当前仅开放 amd64。

## 验收边界

这台服务器只能证明 Debian 12 / amd64 的实机结果。Ubuntu、Rocky、AlmaLinux、CentOS Stream、其他 Debian 版本和 arm64 的 AI 项目仍需相应独立机器验收；本次未重装操作系统，也未把普通容器当作其他发行版的真实主机验收。

未提供第三方模型账号与上游密钥，因此未进行账号所有者的 OAuth 授权或真实模型计费调用。本记录验证的是安装、入口、管理员登录/鉴权、重启、持久化与重复安装保护。
