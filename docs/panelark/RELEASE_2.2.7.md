# v2.2.7：简化更新并消除长时间等待

- 后台更新改为“检测更新 → 下载并安装更新”两步；用户确认一次后，系统连续完成自动备份、下载、签名校验、应用、重启和健康检查，不再停在 50% 等待第二次操作。
- 更新前备份改用数据目录中的本机托管密钥，不再要求管理员为每次更新输入独立密码；自动快照可在原服务器直接预览和恢复。
- 手动迁移备份密码最低长度从 12 位调整为 6 位，同时继续建议使用更长的随机密码。
- 正式发布包直接内置锁定的生产依赖，在线更新和一键脚本优先使用内置依赖，避免因 npm 网络缓慢长时间卡住；旧包缺少依赖时仍保留限时补齐兼容路径。
- 更新状态会以实际运行版本自我校正；独立更新进程超过 12 分钟未报告新进度时，后台显示明确提示，不再让用户误以为仍在正常执行。

从 v2.2.6 或更早版本升级到本版本时，如果旧后台更新停滞，可在 SSH 终端运行 `pa update` 完成这一次升级；升级后后续版本可直接使用新的后台更新流程。
