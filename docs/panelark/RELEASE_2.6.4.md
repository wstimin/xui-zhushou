# v2.6.4：官方 3x-ui 安装与登录交付、安全依赖补丁

包含 [3x-ui 官方安装与交付修复](RELEASE_2.6.3.md) 的全部内容：

- 所有安装入口统一使用 MHSanaei 官方脚本，移除魔改与自定义安装源，旧 `recommended` 参数兼容映射到官方。
- 从官方 `/etc/x-ui/install-result.env` 读取真实账号、密码和 Token；通过官方 CLI 核对当前端口、路径及证书。
- 不再次覆盖官方安装结果、不截断特殊字符密码、不使用计划配置补造交付；实际登录和 Token 验证通过才返回成功。
- 读取失败明确说明原因，并提示通过目标服务器的 `x-ui` 检查；不自动重置已有账号或重复安装。

v2.6.3 的 Linux 全量测试通过，但强制生产依赖审计发现此前锁定的 `body-parser@1.20.8` 受 [GHSA-27r3-jxmh-p828](https://github.com/advisories/GHSA-27r3-jxmh-p828) 影响，发布流程因此停止，没有生成正式 Release。

本版仅将这一间接依赖升级到修复版本 `1.20.9`，未跳过或降低审计要求、未更改 Express 主版本。更新依赖后重新执行全部测试、审计、类型检查和构建。每次推送均更迭版本。

不更新客户服务器，不在客户服务器上安装或覆盖 3x-ui。
