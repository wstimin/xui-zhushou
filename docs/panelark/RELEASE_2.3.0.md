# v2.3.0：新增建站与 AI 面板适配器

## 新增项目

- “建站面板”新增宝塔 Linux 面板，并将 1Panel、aaPanel、宝塔统一归类。
- “AI 面板”新增 New API、One API、CLIProxyAPI（CPA）。
- New API、One API 与 CLIProxyAPI 均使用官方 Docker 镜像和独立持久化目录；目标服务器缺少 Docker 时自动安装并二次验证。

## 安装与安全

- New API、One API 与 CLIProxyAPI 支持修改主服务端口，安装前检查占用并处理本机防火墙。
- CLIProxyAPI 按官方端口映射保留 OAuth 回调端口，自动生成随机管理密钥和 API Key，安装完成后在交付结果中显示。
- CLIProxyAPI 的第三方账号 OAuth 必须由账号所有者在管理中心手动完成，不采集或代填第三方账号密码。
- 宝塔使用官方稳定版安装脚本，安装前检测已有宝塔实例并拒绝覆盖；完成后读取实际安全端口、安全入口和 `bt default` 安装信息。
- Docker 容器使用固定名称和持久化目录；再次执行只恢复已有容器，不重复创建安装包或覆盖现有数据。
- 复用已有 AI 容器前校验原端口映射，阻止误报新端口；CPA 管理密钥和宝塔安装信息纳入敏感交付脱敏。
- 旧版 1Panel 的默认分类及对应 CDK 分类限制自动迁移到“建站面板”，保留原有上下架状态和排序。

## 验证

- 新增四个适配器的系统、架构、内存、磁盘、Docker 依赖、命令白名单、安装命令、HTTP 健康检查和交付结果测试。
- 动态目录与离线目录保持一致，共 15 个面板、6 个工具。
- 新增 [目录项目安装文档](../deployment/CATALOG.md)，说明端口、数据目录、首次登录及 OAuth 操作。
