# PanelArk 阶段 7 运营与迁移说明

## 角色边界

- 超级管理员：全部运营、安全、管理员和备份恢复权限。
- 运营管理员：CDK、站点配置、目录、推荐资源、任务审核和审计。
- 售后人员：CDK 只读、任务查看、人工审核、CDK 权益返还和审计。

所有写操作均要求有效管理会话与 CSRF 令牌，关键动作写入 `audit_logs`。

## 2FA 与会话

在“我的账号”先输入当前密码，再生成 TOTP 密钥。将密钥加入兼容 RFC 6238 的验证器，输入当前六位动态码后启用。启用后登录必须同时提交密码和动态码。

“登录会话”列出当前账号所有有效会话。撤销当前会话会立即退出；修改密码会撤销其他会话。

## `.pgbak` 备份

备份使用 scrypt 从备份密码派生 256 位密钥，再以 AES-256-GCM 加密。归档只包含：

- SQLite 核心业务数据库；
- CDK HMAC 密钥 `panelark.secret`。

归档不包含 SSH 密码、SSH 私钥、远程面板密码或短期 SSH 会话；这些数据本身不会持久化到任务数据库。

手动备份和更新前备份可从后台创建。启用每日定时备份前，在服务环境配置不少于 12 位的 `PANELARK_BACKUP_PASSPHRASE`，再调用后台定时备份开关；密码不会保存到数据库。

## 新服务器恢复流程

1. 初始化新服务器并进入超级管理员后台。
2. 在“备份迁移”上传 `.pgbak`，文件最大 25 MB。
3. 输入备份密码执行预览，确认产品、格式、创建时间、版本和数据库大小。
4. 执行恢复。系统先以同一密码创建 `pre_restore` 快照，再校验 SQLite 核心表、替换数据库并恢复 CDK 密钥。
5. 恢复成功后重新登录，并检查管理员、CDK、目录、推荐资源和审计数据。

若解密、兼容检查、数据库迁移或密钥写入失败，系统会用恢复前数据库与密钥回滚，不保留半恢复状态。恢复前快照保存在数据目录的 `backups/` 中。
