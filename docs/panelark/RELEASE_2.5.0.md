# v2.5.0：后台全栏目管理与任务售后整改

- 超级管理员拥有全部后台业务权限，保留运营/售后角色分工和服务端权限、CSRF 校验。
- 任务详情展示目标服务器、步骤、事件、错误与权益摘要；支持筛选、全部任务导出、审核状态及备注编辑/删除、多条售后处理记录增删改、安全取消及超级管理员删除结束任务。
- 修复运行中提前返还次数与删除审核后重复返还风险；删除任务保留 CDK 权益账本。
- 补齐套餐完整字段编辑/删除、批次重命名/删除、管理员编辑/密码重置/2FA 重置/会话撤销/删除。
- 资源推荐可编辑分类、说明、标签、排序、链接及状态；修复 snake_case 排序字段和排序 0 不生效、带账号密码 HTTPS 链接保存后不可用的问题。
- 目录支持真实上下架、完整编辑、恢复默认，修复部分更新意外覆盖其他字段。
- 站点名称和地址可保存；备份支持备注、可恢复删除、每日定时备份设置；审计支持详情、CSV 导出和按截止日期清理。
- 修复 sql.js 导出重新建立连接后外键约束失效，删除操作的关联级联现在保持有效；已创建过的默认套餐不会在删除后因重启重新出现。
- 新增本机真实 HTTP / SQLite 集成测试与页面 DOM 点击到真实接口的管理链路测试，覆盖创建、编辑、保存、删除、权限与持久化。DOM 测试不等同于真实浏览器视觉验收。
- 不修改客户服务器，升级由管理员自行执行。
